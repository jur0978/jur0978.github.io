关于

我是 jur0978。同样一段话，不同写法花掉的 token 不一样——长堆栈、冗余客套、重复的 JSON 键，都是能省的地方。 tokenlens 估算文本编码后的 token 数，按段落给出占用，并指出那些「意思一样但特别费 token」的表达。它是估算器，不是精确计数器——精确计数依赖具体分词器，这一点它说在前面。

  • 只做文本的 token 占用估算，不做看起来更通用的事。
  • 结论要能追到具体的证据，不接受「一般来说」。
  • 拿不准的地方直接说不确定，不硬凑一个结论。
